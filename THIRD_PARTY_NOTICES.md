# Third-party notices and release status

The generated ROS lint test templates under
`localization_server_TEAM_15/test/` and `path_planner_server_TEAM_15/test/`
retain their Open Source Robotics Foundation copyright and Apache 2.0 notices.
The accompanying license text is in [LICENSES/Apache-2.0.txt](LICENSES/Apache-2.0.txt),
obtained from https://www.apache.org/licenses/LICENSE-2.0.txt.
Those retained templates are unmodified by this integration.

That license applies to the noticed templates; it is not a repository-wide
license grant. Team-authored and inherited course-derived code still requires
an agreed ownership/permission review and repository-level license before an
open-source release. `LicenseRef-Team15-Pending` explicitly records that
unresolved status. A draft integration PR does not resolve it.

No course documents, lab photos, private correspondence, maps, worlds, robot
meshes or downloaded bundles are added by this integration. ROS, Nav2,
TurtleBot4 navigation, OpenCV and numpy remain separately installed dependencies
under their upstream terms.
